# How to cite

Citation information for the accompanying paper will be added once it is
published. In the meantime, cite the software itself and the `v0.1.0` tag:

```bibtex
@software{polypympc_software,
  title   = {{PolyPY-MPC}: Polytope-based Model Predictive Control tools},
  author  = {Faliero, Fabio and Braun-Delvoye, Baptiste},
  year    = {2026},
  version = {0.1.0},
  url     = {https://github.com/Falier0s/polypy-mpc}
}
```
